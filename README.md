# 📊 Sales & Profit Performance Analysis Dashboard (Tableau,Ms-Excel)

## 📌 Project Overview
This project focuses on analyzing retail sales data to uncover sales and profit trends across multiple business dimensions. Using Excel for data preparation and Tableau for visualization, an interactive dashboard was developed to support data-driven business decision-making.

---

## 🧩 Problem Statement
Businesses often struggle to monitor sales and profitability across regions, categories, and cities using static reports. This project aims to create a dynamic and interactive dashboard that enables stakeholders to quickly identify performance drivers and areas requiring attention.

---

## 🛠 Tools & Technologies
- **Excel** – Data cleaning, validation, and preparation  
- **Tableau** – Interactive dashboards, parameters, filters, calculated fields  
- **Data Visualization** – KPI tracking, trend analysis, geo-visualizations  

---

## 📂 Dataset
- Retail sales dataset containing **9,000+ records**
- Key fields include:
  - Order Date  
  - Region, State, City  
  - Category, Sub-Category  
  - Sales  
  - Profit  

---

## ⚙️ Data Preparation
- Cleaned and validated 9,000+ sales records in Excel  
- Handled data consistency and formatting issues  
- Prepared an analytics-ready dataset for visualization in Tableau  

---

## 📈 Dashboard Features
- Interactive analysis of **Sales and Profit**
- Parameter-driven metric selection
- Dynamic filtering by Region, Category, State, and City
- Trend and comparative analysis across dimensions
- Geo-visualizations for state- and city-level performance
- KPI tracking for quick business insights

---

## 🔍 Key Analysis Performed
- Trend analysis to identify sales and profit patterns  
- Comparative analysis across regions and product categories  
- Identification of performance drivers and underperforming areas  

---

## 📊 Key Insights
- Regional and category-level variations significantly impact profitability  
- Certain cities and categories consistently drive higher margins  
- Interactive dashboards enable faster insight discovery compared to static reports  

---

## 🚀 Business Impact
- Enabled data-driven decision-making through consolidated KPI views  
- Improved visibility into sales and profit performance across business dimensions  
- Reduced dependency on manual reporting through automated dashboards  

---

## 📌 Conclusion
This project demonstrates the use of Excel and Tableau to transform raw sales data into meaningful business insights through interactive dashboards, supporting faster and more informed decision-making.
